# Frutiger Dashboard — descargas / downloads

Este repositorio contiene únicamente instaladores y metadatos de actualización. El código de la aplicación se mantiene en un repositorio privado separado.

Las actualizaciones de la aplicación comprueban la firma del instalador y su versión. Las claves privadas y las credenciales de publicación nunca se distribuyen con la aplicación.

This repository contains installers and update metadata only. Application source is maintained separately in a private repository. The in-app updater verifies installer signatures and their signed versions; signing keys and publication credentials are never shipped with the app.
